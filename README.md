## 加一本

1. 复制 `books/_template.md`，改名成书名，正文填进 `## 感言`。
2. 在上面的表格里加一行，链接指向 `books/文件名.md`。

「读完」写年月即可（`2025-03`），不确定就留 `—`。「一句话」是给以后翻目录的自己看的，一句，别写成摘要。
